# Premium/cracked 名单与准入

## 名单的作用

FLP 区分正版名单和非正版名单. `/flp premium` 和 `/flp cracked` 用于切换名单状态; `offline-whitelist` 使用这些已知记录限制玩家进入.

代理模式以代理 FLP 数据库为准. AuthMe/EasyAuth 账号是**本地认证状态**, 不是 FLP 名单成员关系. 创建或删除认证账号不会自动同步 FLP 名单, 删除 FLP 记录也不是重置认证账号.

名单中的正版玩家每次连接仍需通过验证. 非正版玩家通常使用密码登录. 不要直接修改数据库来绕过账号归属检查.

## 离线白名单

`offline-whitelist: true` 时拒绝未知离线 Java 名字, 已知离线名字可以进入认证. 正版路径仍需通过正版验证. 只有认证插件账号, 不代表 FLP 已经知道这个离线名字.

允许离线名字进入时, 在后端执行有权限的 `/flp cracked <玩家>`. 删除非 premium FLP 记录使用 `/flp delete <玩家>`. Premium 记录不能直接删除, 应先检查账号并明确执行切换. 名单不能替代密码, Mojang 验证或 Floodgate 验证.

## 同名离线回退

`secondAttemptCracked` 默认 `false`. 开启后, 对尚未同意正版绑定的名字, 一次确认的正版验证失败可能让后续连接改用密码登录. 第一次发生变化时会提示使用 `/flp premium`.

- 冒用者尝试连接, 不会让已同意的名字降为密码路径.
- 独立服区分会话明确拒绝, 会话服务不可达和验证中断.
- 代理模式无法完全区分验证失败与玩家网络中断. 即使 Mojang 服务可用, 玩家断线也可能被计为失败.
- 验证成功或执行 premium/cracked 操作会清除之前的回退记录.

不了解取舍时保持关闭. 不要把它当成 Mojang 故障或代理配置错误的通用修复方式.
