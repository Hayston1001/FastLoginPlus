# 问题反馈

在 [FastLoginPlus](https://github.com/Hayston1001/FastLoginPlus/issues) 提交问题, 不要误发到上游 FastLogin. 提交前先搜索已有报告.

请提供:

1. FLP 版本及**提交/构建来源**, 尤其是开发构建或从其他服务器复制来的 JAR.
2. 服务端/代理类型和准确版本, Java, 认证插件版本, 相关 ProtocolLib/Floodgate/Fabric Mods.
3. 部署方式: 独立或代理, 转发模式, 各插件安装在哪端, 存储类型, 不公开密钥.
4. 账号情景: 新建或已有, 密码或绑定, Java 或 Bedrock/linked, UUID 策略及最近命令/升级.
5. 按顺序的复现步骤, 预期结果和玩家实际看到的结果, 重连/重启是否改变结果.
6. 两端脱敏启动日志和一次尝试的 debug 日志, 相关配置, 以及能关联此次尝试的时间戳.
7. 已尝试过哪些解决方法, 以及每一步的结果.

移除密码, 生成凭据, 代理 ID, forwarding secret, 必要的内网 IP 和个人信息, 不附整个认证数据库. 涉及漏洞或账号接管时, 若仓库支持 GitHub 私密漏洞报告应优先使用, 不在公开 issue 中发布利用细节或有效密钥.

文档问题请提供页面链接和错误原文. 登录问题请说明玩家实际看到的提示, 不要只用皮肤判断是否验证成功.
